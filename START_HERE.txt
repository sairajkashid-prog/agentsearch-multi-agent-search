EASIEST WAY TO RUN THE PROJECT
----------------------------------------------------------

WINDOWS
  1. Double-click:  START_HERE.bat
  2. Wait while it installs everything (first run: 1-3 min).
  3. Your browser opens automatically at:
        http://localhost:8000
  4. Keep the black window OPEN while using the app.
     Press Ctrl+C in that window to stop the server.

macOS
  1. Double-click:  START_HERE.command
     If macOS blocks it, right-click the file -> Open.
     If it says "permission denied", open Terminal and run:
        chmod +x START_HERE.command start.sh
  2. Your browser opens automatically at:
        http://localhost:8000

LINUX
  1. Open Terminal in this folder and run:
        ./start.sh
     (If needed first:  chmod +x start.sh)
  2. Open http://localhost:8000 in your browser.


REQUIREMENT
----------------------------------------------------------
Python 3.10 or newer must be installed.

  Download: https://www.python.org/downloads/

  WINDOWS IMPORTANT: during installation, tick the box
  "Add Python to PATH". Then double-click START_HERE.bat again.

The launcher automatically:
  - creates a virtual environment (.venv)
  - installs all dependencies from requirements.txt
  - starts the server
  - opens your browser


OPTIONAL: BETTER SEARCH RESULTS
----------------------------------------------------------
The app works 100% free with no API key.

For cleaner search results you can add a Tavily key:
  1. Copy ".env.example" and rename the copy to ".env"
  2. Open .env in Notepad / TextEdit
  3. Set:  TAVILY_API_KEY=your_key_here
  4. Save, then run the launcher again.

Free key: https://tavily.com


TROUBLESHOOTING
----------------------------------------------------------
"Python was not found"
    Install Python 3.10+ and enable "Add Python to PATH".

"Port 8000 is already in use"
    Close the other program using port 8000, or create a .env
    file containing:   PORT=8010
    Then run the launcher again.

Browser did not open
    Open http://localhost:8000 manually.

Dependency installation failed
    Check your internet connection and run the launcher again.

Want a clean reinstall?
    Delete the ".venv" folder and run the launcher again.
